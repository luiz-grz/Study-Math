📐 Study Math — Site Institucional

Site institucional do **Study Math**, um espaço de reforço escolar e aprimoramento da aprendizagem localizado em Niterói (RJ). O projeto foi desenvolvido com HTML, CSS e JavaScript puro, utilizando Tailwind CSS para estilização.

🌐 Sobre o Projeto

O Study Math oferece aulas personalizadas para alunos do Ensino Fundamental I, II e Médio, com foco em metodologia individualizada e atividades maker. Este repositório contém o código-fonte do site institucional da escola.

O site apresenta:
- Apresentação da proposta pedagógica
- Listagem de serviços e disciplinas atendidas
- Diferenciais do espaço
- Galeria de fotos
- Formulário de agendamento de aula experimental
- Informações de contato e mapa de localização

🛠️ Tecnologias Utilizadas

- **HTML5** — estrutura das páginas
- **CSS3** + **Tailwind CSS** — estilização e responsividade
- **JavaScript** — interatividade (menu mobile, galeria, modal de matrícula)
- **Google Fonts** — tipografia (Inter e Poppins)
